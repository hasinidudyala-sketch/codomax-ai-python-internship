## 1. What is Artificial Intelligence (AI)?
Artificial Intelligence is a field of computer science that develops systems able to perform tasks that normally require human intelligence. Examples include understanding speech, recognising images, and answering questions.

**Examples:** voice assistants, navigation apps, fraud alerts, and image recognition.

## 2. What is Machine Learning (ML)?
Machine Learning is a part of AI. It allows computers to learn patterns from data and use those patterns to make predictions or decisions, instead of writing every rule manually.

**Example:** an email spam filter learns patterns from examples of spam and normal emails.

## 3. What is Deep Learning (DL)?
Deep Learning is a part of Machine Learning that uses multi-layer neural networks. It is useful for tasks such as image recognition, speech recognition, and language processing.

## 4. Difference between AI, ML, and DL
- **AI:** the broad field of making computers perform intelligent tasks.
- **ML:** a part of AI that learns patterns from data.
- **DL:** a part of ML that uses multi-layer neural networks.

Relationship: **Deep Learning ⊂ Machine Learning ⊂ Artificial Intelligence**.

## 5. Real-world applications
- Healthcare: helping analyse medical images.
- Education: personalised learning tools.
- Banking: detecting unusual transactions.
- Transport: route planning and driver-assistance systems.
- Agriculture: crop monitoring from images and sensor data.
- Shopping: product recommendations.

## 6. Python basics
Python is a beginner-friendly programming language used in automation, web development, data analysis, and AI/ML.

### First program
```python
print("Hello, World!")
```

### Variables and data types
```python
name = "Hasini"
age = 20
learning_ai = True

print(name)
print(age)
print(learning_ai)
```
A variable stores a value. Common data types include `str` (text), `int` (whole number), `float` (decimal number), and `bool` (`True`/`False`).

### Conditions
```python
marks = 82

if marks >= 40:
    print("Pass")
else:
    print("Fail")
```

### Loops
```python
for number in range(1, 6):
    print(number)
```
A loop repeats a block of code.

### Lists
```python
topics = ["AI", "Machine Learning", "Python"]
print(topics[0])
```
A list stores multiple items in one variable. Python list indexing starts at `0`.

### Functions
```python
def greet(name):
    print("Hello", name)

greet("Hasini")
```
A function is a reusable block of code.
